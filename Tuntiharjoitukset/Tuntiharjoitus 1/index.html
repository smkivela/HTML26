Ohjelmointikielten oppiminen

Haluan oppia vuoden aikana mahdollisimman monta ohjelmointikieltä.

  • HTML

    Haluan oppia rakentamaan verkkosivujen rakenteita ja ymmärtämään, miten HTML:ää käytetään verkkosivujen sisältöön.

  • CSS

    Haluan oppia muotoilemaan verkkosivuja ja tekemään niistä visuaalisesti kiinnostavia ja toimivia.

  • JavaScript

    Haluan oppia tekemään verkkosivuista interaktiivisia ja ohjelmoimaan niiden toiminnallisuuksia.

  • C++

    Haluan oppia C++:aa mahdollisimman nopeasti, jotta voin alkaa kehittää omia työkaluja musiikin tekemiseen.
